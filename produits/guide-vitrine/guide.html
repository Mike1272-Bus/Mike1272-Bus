C'est quoi, une mini-vitrine ?

Une seule page, faite d'abord pour le téléphone. On y voit tes produits, et sous chacun un bouton « Je veux celui-ci ». La cliente touche le bouton : WhatsApp s'ouvre avec son message déjà écrit, elle n'a plus qu'à l'envoyer.

Pour une vendeuse qui vend sur WhatsApp, c'est un lien à mettre dans son statut, sa bio TikTok ou sur une carte avec un QR code.

Ce qu'il te faut

  • Une IA : Claude ou ChatGPT (la version gratuite suffit pour commencer).
  • Un compte GitHub gratuit, pour mettre la page en ligne.
  • Les photos des produits, nettes, à la lumière du jour.
  • Le numéro WhatsApp qui recevra les commandes.

ÉTAPE 4

Le secret : le bouton WhatsApp

C'est ce bouton qui transforme une visite en commande. Voici à quoi il ressemble dans le code :

  • wa.me/ puis ton numéro : 243 + le numéro, sans le +, sans le 0 du début, sans espaces.
  • ?text= puis le message. Les espaces deviennent %20 : l'IA le fait pour toi.
  • Un message différent par produit : tu sais tout de suite ce que la cliente veut.

ÉTAPE 5

Mets-la en ligne gratuitement

Avec GitHub Pages, depuis un ordinateur ou le navigateur du téléphone :

  1. Crée un compte sur github.com.
  2. Bouton New : donne un nom (ex. pagnes-maman-rose), laisse Public, puis Create repository.
  3. Clique uploading an existing file et ajoute index.html et tes photos, puis Commit changes.
  4. Va dans Settings puis Pages : Source Deploy from a branch, branche main, dossier / (root), puis Save.
  5. Attends une à deux minutes. Ton lien apparaît en haut de la page :
    ton-nom.github.io/pagnes-maman-rose

Ce lien, tu le mets dans ton statut WhatsApp, ta bio TikTok, ou dans un QR code sur une petite carte.
