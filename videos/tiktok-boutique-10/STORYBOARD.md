## Video direction

- **Palette system** (BlockFrame): offwhite resting canvas, one pastel wash per frame — blue (accroche), pink (situation), cream (vrai probleme), yellow (consequence), green (declic), blue (solution), pink (benefice), pink/yellow split (CTA).
- **Sequential images per scene, hard cut** (standing rule since video 7): each narrative scene shows one image at a time, full-hero, timed to a slice of that scene's voice-off duration; never two images visible together. Number of images varies per scene (3 to 5) based on what the user supplied per paragraph.
- **Single-image frame** (CTA): held for the whole line, spring-pop + particle-burst treatment.
- **Captions — mandatory standing rule since video 4**: every voiceover line captioned, word-grouped, synced via the shared BlockFrame caption skin (root-level captions track). Keep all content above y=1600px.
- **Tone**: pedagogique/doux, second person ("tu"), never "je".

## Real assets

See BRIEF.md for the full per-scene file map. 25 images supplied by the user (mapped by paragraph), 2 replaced by agent-generated BlockFrame illustrations (watermarked originals), 1 CTA image generated by the agent per explicit request.

Kokoro TTS (`ff_siwis`, French) per-line, staged at `audio/lines/NN.wav` with word timing at `audio/lines/NN.words.json` (deterministic character-weighted estimate — no network ASR available in this environment).
